# vibecoding-optimization

[English](./README.md) | 中文

这是一个面向编程任务的技能，可以提升 vibecoding 过程中的体验，并提升代码的可靠性、可读性与可维护性。

## 安装

```bash
npx skills elysias123/vibecoding-optimization
```

## 使用方法

- 在进行编程开发等相关任务时自动激活
- 使用 `/vibecoding <on/off>` 或 `/vibecoding-optimization <on/off>` 控制
